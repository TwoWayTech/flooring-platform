## Decisions and why
All of these are recorded in ADR 0028.
- **tsup with SWC for the API build.** The workspace packages are TypeScript source, and Nest needs decorator metadata. npm packages stay external, so apps/api lists the runtime dependencies of the workspace packages it bundles. Without them the built API failed with "Cannot find package 'postgres'".
- **Statuses are `text` typed with the shared unions,** not PostgreSQL enums, so migrations stay easy.
- **Ids.** UUID v7 is made in the app. The seed uses UUID v5, so running it twice gives the same ids.
- **Better Auth tables** are generated by `@better-auth/cli` 1.7.21 from a throwaway config and are exempt from the table rules. P8 must regenerate them when the real auth config exists, and set UUID user ids.
- **Settings** are one jsonb row per group. Tax rules and county rates are their own tables, because they have effective dates. Branding sits in the control database.
- **CI follows the owner's mid-session change,** plus one addition: draft pull requests skip `verify` and `e2e`. Otherwise every WIP push to an open PR would cost about 30 minutes.
- **`.env.example` was not written.** The deny rule `Edit(./.env.*)` covers it, so docs/environment.md lists the variable names instead.
- **The bundled API never runs migrations;** scripts do. The migration folder paths assume the source layout.
