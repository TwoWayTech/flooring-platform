## Decisions
- Monthly meetings repeat on the same weekday of the same week ("the third Thursday"); a fifth-week start moves to the fourth week so no month is skipped.
- Fixture meetings shift by whole weeks, like timesheet weeks, so a meeting keeps its weekday when the demo runs on a later day (`WEEKLY_KEYS` in date-shift.ts).
- The fixture generator places meetings on workdays and starts recurring series weeks before the anchor, so every week of the calendar has its standing meetings. Only the meetings in the fixtures changed.
- Full-value tooltips follow each number kind's maximum decimals (fixed in d3a83d3 after a unit test failure that a piped command had hidden; test commands now record the exit code before filtering output).
