## Decisions and why
- **Stack procedure (#46 to #54, and each later stacked PR).** For each PR: `git diff <head of the PR below> origin/main --stat` must print nothing; then `git merge -s ours origin/main`; then `git diff HEAD^1 --stat` must print nothing; push; `gh pr ready <n>`; check that a `pull_request` run really started; merge with `--match-head-commit`. With both diffs empty the code is exactly what was reviewed, so no new review was needed.
  - The `ready_for_review` run sometimes doesn't start. `gh pr ready <n> --undo`, then `gh pr ready <n>`, starts it.
  - A skipped draft `synchronize` run on the same commit shows as "skipping" in `gh pr checks`. It can be ignored when the real run is green.
- **The owner's answers first** (#55), then each answer built in its own small PR (#56 to #59), each with a security review, before part 3b.
- **Installation jobs are not built.** `installation.calendar` is switched off with status `removed`; Contracts replaced it (blueprint-delta, 2026-11-10). Turning it back on is the owner's decision, so it is an owner question.
- **Stock adjustments stay off** (`removed`) and have no API (PR #66 Q1). Only the Stock rules section moved.
- **P6 / F-r is not built.** Moments sent with no zone mark touch every module, so the format is the owner's decision.
- **The CI timeout was not raised.** The owner allowed raising `verify` to 40 minutes only after two cancellations; there was one.
- **Parallel builds** each ran in their own worktree; ports 3000 and 4000 were handed to one builder at a time for Playwright.
