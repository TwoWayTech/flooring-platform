### Key decisions
- **One plan for both sides.** The API and DemoStore run the same shared `planImport` and kind rules on their own records. The server never parses a file: the browser turns it into text cells and sends only the mapped columns as JSON; the API re-reads every cell with `readCell` and stores no file.
- **Access.** `settings.import.manage`, company-wide data scope, the kind's own view, create and edit keys, and the sensitive key of any sensitive column mapped. The company only from the session; a body naming a company is a 400.
- **What you saw is what you get.** Commit and Undo need a step-up. The commit runs in one transaction under a per-company advisory lock and `SHARE ROW EXCLUSIVE` table locks, re-plans against current records, and is refused (409 `plan_changed`) if any row's action differs from the dry run's.
- **Exact Undo.** Refused unless every record still equals what the import wrote, every reference it puts back is live, and no live record refers to a created one (foreign keys from the catalog plus the polymorphic links). Created records are soft-deleted.
- **Audit.** One entry per record and one per batch, in the same transaction; saved columns are audited too. The dry run writes nothing.

## Decisions and why
Each goes into ADR 0057 "Safest options taken", the blueprint-delta row and the spec's "Real build" section.

1. **S-1 Part 1 only** (customers, addresses, suppliers, products); the API answers 404 for the other kinds. Why: none of them posts to the ledger or touches pay, their loaders exist on the API, and Undo can be exact for them.
2. **S-2 Company-wide scope.** Why: matching reads every record (otherwise an existence oracle), and a row may set another rep, which moves the customer's "own" scope.
3. **S-3 The kind's own keys** on top of `settings.import.manage`; products also need `purchasing.supplier.view` and `inventory.product.view_sensitive`. Why: nobody grants more than they hold.
4. **S-4 Sensitive columns** (credit limit, cost) need the key that reveals them; a supplier's credit limit needs both the customer-credit key and a supplier-money key. Why: rule 5.
5. **S-5 Stock history freezes a product's cost, category, unit, coverage and width,** for the import and for Undo; stock in transit counts. Why: cost follows receipts and average cost; changing it under stock would break inventory value.
6. **S-6 Retired SKUs are refused,** because `products_sku_uidx` is not partial on `deleted_at`.
7. **S-7 Step-up for commit and Undo;** `MFA_REQUIRED_KEYS` unchanged (an auth change is the owner's).
8. **S-8 Active reps only.**
9. **S-9 Strictest terms:** a new supplier without Terms gets Pay on order (the module's default, not the spec's Net 30); a new customer gets Due on receipt (the spec), never the company default.
10. **S-10 What you saw is what you get** (the `expected` action string); all valid rows commit or none.
11. **S-11 Idempotent re-imports:** decimals compared as decimals, a supplier address by its four fields, categories as a set.
12. **S-12 Limits:** only mapped columns; 2,000 rows, 60 columns, 1,000-character cells, module field lengths and digit caps; a 100 KB request (body limit unchanged); one import operation at a time per company; 50 commits per 24 hours; a 10-second lock timeout.
13. **S-13 More audit:** per record plus per batch; saved columns audited (rule 10).
14. **S-14 Undo stays exact** (above).
15. **S-15 Nothing leaves that needn't:** batches never carry `changes`, `savedBy` is dropped, `Cache-Control: private, no-store`, no file stored, the wizard's own CSVs neutralise formula cells.
16. **S-16 Ambiguous keys refused:** an External ID, email, name or SKU matching more than one record is a row error, never "the first one".
17. **S-17 Hidden control characters refused** in cells (except tab and line breaks in a timesheet note), headers, file names and mappings.
18. **S-18 Product rules:** coverage and width more than 0; cartons need coverage in every category; carpet needs a width; prices and costs fit `numeric(14,4)` after conversion; a supplier that matches exactly one record.
19. **S-19 Blank means blank in the chosen columns,** in both modes.
20. **S-20 Sensitive columns are never auto-mapped** for someone who can't use them.

Not taken: escaping formula cells in the app-wide `data-table/csv.ts`. It is shared by every list export and needs its own rule for negative numbers; it stays an open STATUS item (owner question 11).
