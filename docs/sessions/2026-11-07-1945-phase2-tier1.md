## Decisions
- The company collects tax in a state when its tax settings hold a rule for that state; the quote builder, conversion and the generator all use `taxContextFor`.
- Invoice screen and PDF render one `InvoiceModel`, so they match by construction.
- Scroll containers are `relative` so visually hidden labels cannot widen the page (found with the phone overflow test).
- Grids that only define columns from `lg` now set `grid-cols-1` below it, so wide content scrolls inside its panel.
- Forms validate on change once touched, so fixing a field never shifts the Save button under the cursor.
- Screenshots per screen: 1440 and 390 px across both themes, viewed in pairs (one light, one dark); a phone test checks every screen for sideways scroll.
