# Click-through notes

A click-through of the real product in api mode, following docs/demo-script.md persona by persona, written down as it happened. No product code was changed during the session.

## 2026-11-21 (Claude, unattended run)

- Build: `main` at a86a5bd, production builds of web (api mode, `NEXT_PUBLIC_DATA_SOURCE=api`) on http://localhost:3000 and the API on http://localhost:4000.
- Database: `docker compose down -v`, `up -d`, `pnpm db:migrate`, `pnpm db:seed` with a throwaway `SEED_USER_PASSWORD`, all with the local default URLs from docs/environment.md set inline. The local encryption key and a throwaway `BETTER_AUTH_SECRET` were set inline; `.env.local` was not read.
- Seeded: Summit Floor Co. only (15 users). **The repo has no seed for the HR Suite company (Harbor Staffing Co.)**, so section 5 could not be signed into. There is no seed command for a platform admin either; Dana was made one with the e2e helper `setPlatformAdmin` from `packages/db/src/testing.ts`.
- Browser: Claude in Chrome. The screen allowed a viewport of only 894 x 577 CSS px (1280 x 672 screen at 150 % scaling), so the walk-through ran at that width; 1440 px and 375 px in both themes were checked by a scripted headless Playwright sweep (see "Width and theme sweep").
- MFA: enrolled through the screen; codes computed with a local RFC 6238 script. Setup keys and backup codes stayed in the session scratchpad.

Severity: **blocker** stops the script step; **major** wrong result or missing function; **minor** works but is off; **wording** text only.

### Fix first

1. **#26 My pay crashes** for every person who opens it ("[DecimalError] Invalid argument: undefined"); the Employee's own pay page is unusable.
2. **#13 and #39 The books and the reports disagree.** The seed has no opening balances, so the ledger goes negative as old documents are settled, and the Business report and Profit and loss give different net profits for the same month ($24,335.57 vs $102,507.79).
3. **#55 A display setting changes customer documents**: with money at 0 decimals the invoice PDF shows $2.57 as "$3" and totals that don't add up. Also on documents: #10 (terms "Due on receipt" with a 30-day due date) and #11 (the "≈" sign prints as "H").
4. **#53 and #47 Controls that are too loose**: the default Sales role can record customer payments, and approving a whole pay period needs no confirmation or code, while saving branding does.
5. **#67 Seed the HR Suite company** (and a platform admin) so the whole demo script can run in api mode, then re-run section 5. Close behind: #44 (dragging a meeting resizes it but says "moved"), #57 (audit times in unlabelled UTC), #31 (Schedule of values without billed and retained), #1 (best sellers with no product names).
