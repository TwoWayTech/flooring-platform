# Flooring Platform

A multi-company platform for US flooring businesses (the Flooring Suite), with an HR Suite on its own address.

This repository currently holds the clickable demo. To run, test or deploy it, see [README.demo.md](README.demo.md).

This file will become the full README of the real product when its build starts. The plan for that build is in `docs/blueprint/`, with the changes decided after the demo in `docs/blueprint-delta.md`.
